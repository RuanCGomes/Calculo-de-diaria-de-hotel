# Calculo-de-diaria-de-hotel

Este repositório serve para ambas as agendas 13 e 14 de Desenvolvimento de Sistemas, já que a 14 é praticamente igual à 13, apenas com mais uma página. De qualquer forma, ainda assim estão separadas em duas pastas diferentes.

O "MauiAppHotel-master" é para a agenda 13, e o "MauiAppHotel-2-master" é para a agenda 14, com imagens do seu funcionamento dentro de cada página. Não tive muito o que mudar em relação à estética, então tentei pelo menos mudar para umas cores mais chamativas/distintas.

É um pouco de um incômodo ter de fussar com o código-base por, sendo ele de anos atrás, estar desatualizado, mas acho que mesmo assim consegui fazê-lo funcionar decentemente. Até tive dificuldades em fazer o upload dos arquivos, tendo que deletar as pastas "obj" e "bin". Mas enfim, até a próxima!
